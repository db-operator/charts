Breaking changes and migration paths:

Version `4.0.0` brings a new DbInstance API. Old API (v1beta1) is not reconciled by the operator anymore.
It's is not remobed from the CRD yet, but there will be no conversion webhook, so older version will not
be migrated automacially.

Users of the `db-instances` helm chart should update the chart version to `3.0.0` with the same config,
new features, that are now supported by the instances will be delivered to the chart later.
